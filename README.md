## 🚀 Featured Projects

### 🍎 [FoodLog](https://github.com/FoodLog-Team/foodlog-backend)

A backend for a nutrition-tracking application with AI-powered food analysis and personalized nutritional targets.

**Tech Stack:** Java 21 · Spring Boot 4 · Spring Security · Spring AI · PostgreSQL 17 · Flyway · Maven · Docker

- JWT authentication with access and refresh tokens, rotation, and reuse detection.
- Concurrency-safe refresh-token management using PostgreSQL advisory locks.
- AI-powered food analysis using Google Gemini through Spring AI.
- User nutrition profiles and personalized calorie and macronutrient targets.
- Database migrations with Flyway and PostgreSQL integration testing with Testcontainers.

### ♟️ [ChessTracker](https://github.com/illia-krupko/chess-tracker) · [API Gateway](https://github.com/illia-krupko/chess-tracker-api-gateway) · [Infrastructure](https://github.com/illia-krupko/chess-tracker-infrastructure)

A microservices backend for chess games, Stockfish analysis, AI-generated explanations, and player statistics.

**Tech Stack:** Java 21 · Spring Boot · Spring Security · Kafka · PostgreSQL · Liquibase · Docker

- Kafka-based asynchronous chess analysis workflow.
- Integration with Stockfish chess engine and Google Gemini.
- RSA JWT validation at the API Gateway and trusted identity propagation.
- Independent services with separate database schemas and Liquibase migrations.

### 🚗 [CarSharingApp](https://github.com/illia-krupko/car-sharing-app) · [Live API Docs](https://portfolio-carsharing.duckdns.org/api/swagger-ui)

A deployed Spring Boot REST API for car rentals, featuring JWT authorization, concurrency-safe reservations and returns, Stripe payments, and Telegram notifications.

**Tech Stack:** Java 17 · Spring Boot · Spring Security · PostgreSQL · Liquibase · Docker · AWS EC2

- **260+ automated tests**, **95.8% line coverage**, **100% branch coverage**.
- Atomic database updates and pessimistic locking to protect rental inventory.
- Integration testing with PostgreSQL Testcontainers.
- CI/CD with GitHub Actions and AWS EC2 deployment.

### 🔐 [JWT CLI Tool](https://github.com/illia-krupko/jwt-cli-tool)

A Java command-line tool for decoding, encoding, and verifying JWTs without using a JWT library.

- Implements JWT operations using JDK cryptography APIs.
- Tests cover RFC 7515 examples, signature tampering, and algorithm-confusion cases.
